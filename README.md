# Osu Auto Download

A simple Userscript to automatically download beatmaps when visiting a beatmap set page on the official Osu! website.

## Installation

Click the badge below to install the script (requires Tampermonkey or Violentmonkey):

[![Install](https://img.shields.io/badge/Install-Script-brightgreen?style=for-the-badge&logo=tampermonkey)](https://github.com/HakkaYoro/osuDwn/raw/main/osuDwn.userscript.js)

## Features

- Works on all Osu! website languages (uses CSS classes instead of text).
- Supports dynamic page navigation.
- Lightweight and fast.
- Automatically handles page loading states.
